Oui, notre solution GPS fonctionne même dans les zones de montagne autour de Grenoble. Vos véhicules sont suivis sur les routes d'accès à Chamrousse, l'Alpe d'Huez ou les Deux Alpes.

Le GPS flotte détecte les ralentissements sur les axes autoroutiers grenoblois et propose des itinéraires alternatifs. Vous pouvez aussi identifier les fenêtres horaires optimales pour vos tournées.
